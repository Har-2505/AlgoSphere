# AlgoSphere 🚀

A coding practice and interview preparation platform.

## About Project

AlgoSphere is a LeetCode-style platform where developers can practice Data Structures and Algorithms problems, solve coding challenges, and improve their problem-solving skills.

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
